# MyStreet
Civic infrastructure transparency platform.
Every road. Every rupee. Every official. Permanently public.

## Stack
- Next.js App Router
- TypeScript
- Tailwind CSS
- Drizzle ORM
- NeonDB (PostgreSQL)
- Vercel

## Structure
- src/app — pages and API routes
- src/components — reusable UI
- src/server/db — database client and schema
- src/lib — shared utilities
- src/types — TypeScript types
